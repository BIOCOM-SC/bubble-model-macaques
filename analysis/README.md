# analysis/ - tables and figures of the paper

Python collects the run outputs into plain-text files; gnuplot draws the figures.

```sh
./plot_all.sh                     # collect.py + lung_qc.py (need runs/work/), then all figures
./plot_all.sh --plots             # figures only, from the included data/
./plot_all.sh --plots fits        # only some figures (names of plots/*.plt)
```

`plot_all.sh` uses `python3` (set `PYTHON=/path/to/python` for another one), writes EPS with gnuplot
and converts it to PDF (`epstopdf`) and PNG previews (Ghostscript) in `out/`.

## Scripts

- `collect.py` - reads `runs/work/<run>/` and writes `data/` (inputs of the gnuplot scripts) and
  `tables/` (numbers quoted in the paper). `python collect.py --help` lists its parts;
  `python collect.py fits prcc` runs only some.
- `lung_qc.py` - checks of the virtual lung (`lung/`): terminals outside their lobe mesh,
  distances to the walls, terminal diameters -> `data/lung_*.dat`, `tables/lung_qc.txt`.
- `plots/*.plt` - one gnuplot script per figure, run from `plots/` (`gnuplot fits.plt`);
  `common.gp` (styles, axis labels), `panels6.gp` (six outputs: model mean +/- SD and data),
  `family6.gp` (one-parameter families coloured by the parameter value).

equivalent to the optimum, Suppl. table), `lung_qc.txt`. Table 2 (experimental targets) is
`data/processed/summary.txt`.

## Conventions

- Row k of the model's `results.txt` is the state at the end of day k + 1 (the fit error uses
  rows 20, 52, 76 = days 21, 53, 77); the curve files in `data/curves/` carry day = k + 1.
- Curve files: `day NC sd NM sd NMD sd NMI sd VFC sd MAC sd` (as `data/exp.dat`); missing values
  (aborted cases) are NaN.
- The per-case curves of the 1000 PRCC samples (`data/curves/prcc/`) are not included (they are
  regenerated by `collect.py prcc`); `data/prcc_*.dat` are.
